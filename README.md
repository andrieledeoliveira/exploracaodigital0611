# SCOTT - Diagnóstico 360º de Maturidade Digital

SCOTT é uma aplicação web interativa em arquivo único (`index.html`) projetada para diagnosticar a maturidade digital de empresas com base em 4 pilares estratégicos: **Infraestrutura & Nuvem**, **Sistemas Empresariais (ERP/CRM)**, **IA Generativa & Automação** e **Governança & LGPD**.

---

## Funcionalidades Principais

- **Avaliação Multidimensional:** Formulado com 8 perguntas estratégicas distribuídas nos 4 pilares.
- **Painel de Resultados (Dashboard):** Cálculo automático da pontuação (0 a 100%), classificação de estágio e visualização em gráfico Radar via Chart.js.
- **Modo Demonstração:** Botão de carregamento de dados fictícios para testes rápidos.
- **Plano de Ação Dinâmico:** Recomendações técnicas personalizadas baseadas no desempenho individual de cada pilar.
- **Exportação Limpa:** Suporte a exportação/impressão em PDF via `window.print()` otimizado por CSS media print.
- **Privacidade por Design:** Processamento local de dados no navegador sem envio a servidores externos.

---

## Estrutura dos Pilares

1. **Infraestrutura Digital e Nuvem:** IaaS, PaaS, SaaS, política de backup 3-2-1 e alta disponibilidade.
2. **Sistemas Empresariais e Fluxo de Dados:** Integrações entre ERP e CRM, eliminação de planilhas isoladas.
3. **Inteligência Artificial e No-Code:** Automação de processos operacionais e aumento de produtividade.
4. **Governança, Ética e Segurança:** Conformidade com a LGPD, autenticação MFA e controle de acesso.

## Como Executar

### Execução Local

1. Clone o repositório ou faça o download do arquivo `index.html`.
2. Abra o arquivo `index.html` em qualquer navegador web moderno.

### Publicação no GitHub Pages

1. Faça o commit do arquivo `index.html` no repositório principal.
2. Acesse **Settings** > **Pages** no repositório do GitHub.
3. Selecione a branch `main` e a pasta `/ (root)`.
4. Salve as alterações. O site estará acessível no link fornecido pelo GitHub.
